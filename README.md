### Задание 1 (1-2 уровни)

Для реализации модульного разделения проекта был выбран механизм Webpack Module Federation. Это решение обусловлено двумя ключевыми факторами: во-первых, проект полностью реализован на едином фреймворке, что обеспечивает совместимость компонентов, а во-вторых, имеется успешный практический опыт работы с данной технологией, что минимизирует риски внедрения.


Для разделения была выбрана стратегия **Вертикальная нарезка**. Были выделены следующие микрофронтенды:

- **Auth** - реализует функционал авторизации;
- **Card** - отвечает за работу с фотографиями;
- **Profile** - управляет созданием и редактированием профиля пользователя;
- **Host** - является точкой входа и объединяет все остальные микрофронтенды
